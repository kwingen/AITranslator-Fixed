# v2.2.4-fixed.1 — 可靠性修复预览版

非官方修改版，基于 FireFrog / jxq1997216 的 AITranslator v2.2.3（741b0dd）。保留 GPL-3.0、上游历史和作者署名。

## 已修复

- KV / Translator++ 重翻校验并保存最新结果；TPP 降级翻译使用稳定键。
- SRT 非连续 cue ID、时间戳、清理过滤、旧错位断点与覆盖率校验；各格式不再静默合并缺项。
- 缺模板时启动或手动合并不会删除任务；手动合并失败恢复原状态。
- 外部导入只读；内部原子检查点、前一版本备份、损坏/缺失主文件恢复和配置恢复；重翻失败项不会被备份复活。
- 最终输出放到独立 `output/`，防止覆盖内部数据；阻止任务/输出名称中的路径穿越。
- 拒绝截断、空回复、过滤、拒绝、重复控制字段和不完整思考标签；安全处理明确启用的前导思考块兼容。
- 扩展参数结构化合并、null 省略、max_completion_tokens 切换；禁止覆盖原文 messages 或模型选择。
- 有分类的有界重试、可取消 Retry-After/退避；上下文裁剪和逐条降级，在后续请求失败前保留已完成条目的检查点；默认不跟随重定向转发原文。
- API Key / SMTP 授权码使用当前用户 DPAPI，兼容旧配置及两种备份迁移；目的地址变化需重新输入凭据，发送/保存使用同一不可变快照。

## 使用与边界

- 附件是面向外部 Sakura / llama-server / OpenAI 兼容服务的 Windows 框架依赖版，需要 **.NET 8 Windows Desktop Runtime x64**。
- 不捆绑模型或更新后的 llama/CUDA/Vulkan 原生后端；未做真实 GPU 加载或付费模型推理验证。
- Windows CI 模板位于 `ci/windows.yml`；当前 OAuth 缺 `workflow` 权限，**云端 CI 未启用**，不要把本机通过理解成云端通过。
- 精确 token 预算、RPM/TPM 调度、超长单条安全拆分、隔离并发、.NET 10 / 原生后端升级和脚本沙箱/执行授权留待后续。
- `.csx` 仍是可执行 C#，只运行可信脚本。更新旧安装前备份整个软件及翻译目录，不要直接覆盖唯一成果副本。

完整用法、迁移和恢复说明见 `docs/MAINTENANCE.md`、`docs/VERIFICATION.md`。
